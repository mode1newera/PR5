## Описание

Программа «Обработчик анкет» проверяет ФИО, электронную почту, телефон и группу.
Она выводит таблицу принятых анкет, ошибки и статистику, а также сохраняет результаты.

## Файлы

- `main.py` — запуск программы и обработка ошибок.
- `validators.py` — проверка полей и разбор строки.
- `storage.py` — чтение и сохранение текстовых файлов.
- `report.py` — таблица, маскировка номера и статистика.
- `anketa.txt` — примеры исходных данных из четырёх полей.
- `test_checks.py` — простые тесты программы.
- `.gitea/workflows/tests.yml` — CI для учебной Gitea.
- `.github/workflows/tests.yml` — CI для GitHub.

## Запуск

Нужен Python 3.12 или совместимая версия.

```powershell
python main.py
```

Можно указать другой файл: `python main.py anketa.txt`.
Формат каждой строки: `ФИО;почта;телефон;группа`.
Результат появится в терминале и в файлах `ok.txt`, `errors.txt`.

## Проверка

```powershell
python -m pip install pytest
python -m pytest -q
```
